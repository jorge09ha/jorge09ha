## 🧭 Cómo trabajo

**Documentación y código van juntos.**
Las decisiones técnicas, los diagramas, las especificaciones y el código forman parte del mismo proceso de construcción.

**Primero entiendo el problema.**
Modelo los procesos, los actores y las restricciones antes de agregar tecnología.

**Construyo de forma incremental.**
Divido los sistemas grandes en componentes pequeños y validables, para corregir decisiones temprano.

**Valido en entornos reales.**
Mi experiencia en infraestructura me acostumbró a comprobar cómo se comportan los sistemas de verdad, no solo en el diseño.

# 👋 Hi, I'm Jorge Hernández

**Software Engineer · Networking & Infrastructure · Co-founder of [Gufora](https://gufora.com/)**

I'm a software engineer and co-founder of [Gufora](https://gufora.com/), a software development company focused on SaaS platforms and tools for businesses.

My experience has a strong foundation in **enterprise networking and infrastructure**: switching, routing, perimeter security, servers, virtualization, and automation. That combination lets me see software from the architecture and platform design down to the infrastructure where it finally runs.

Today I'm specializing in **software architecture**.

---

## 🚀 What I work on

- **Software engineering:** web applications, SaaS platforms, and multi-tenant systems
- **Backend and APIs:** services, integrations, and business logic
- **Automation:** operational processes and network infrastructure
- **Networking:** switching, routing, security, and enterprise network troubleshooting

---

## 🏗️ What I'm building

- **SaaS platforms:** multi-tenant systems with organizations, users, roles, permissions, and operational workflows
- **Business tools:** internal systems for information, asset, process, and audit management, and for automation
- **Networking tools:** automation of network configuration processes through APIs
- **Integrations:** services that connect applications, APIs, and external systems

---

## 🌐 Networking & Infrastructure

`Switching` · `Routing` · `Enterprise Networks` · `Network Security` · `SD-WAN` · `Servers` · `Virtualization` · `Network Automation`

I work mainly with enterprise networks, and with diagnostics, operations, and infrastructure automation.

---

## 🧠 Software Architecture

I'm specializing in:

- SaaS and multi-tenant architectures
- Modular design and domain modeling
- APIs, service contracts, and asynchronous processing
- Security, authentication, roles, and permissions
- Auditing and traceability
- Scalability, maintainability, and stack decisions with their trade-offs
- Architecture documentation and ADRs

---

## 🧭 How I work

**Documentation and code go together.**
Technical decisions, diagrams, specifications, and code are part of the same building process.

**I understand the problem first.**
I model processes, actors, and constraints before adding technology.

**I build incrementally.**
I split large systems into small, verifiable components so decisions can be corrected early.

**I validate in real environments.**
My infrastructure background taught me to check how systems actually behave, not only how they are designed.
